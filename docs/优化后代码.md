## 各模块详细说明

### config.py - 配置管理模块

**功能**：
- 环境变量管理
- 路径配置
- 工具函数（目录创建等）

**主要函数**：
- `_env_or()`: 从环境变量获取配置或返回默认值
- `ensure_dir()`: 确保目录存在，不存在则创建

---

### utils - 工具模块

#### logging.py - 日志记录
- 双输出日志（终端 + 文件）
- 支持上下文管理器

#### save_img.py - 图像保存
- 按命名规范保存中间结果
- 支持 JPEG/PNG 格式
- 自动创建输出目录

#### ToPrint.py - 统计输出
- 拼接管线统计信息
- 双输出到终端和文件

---

### matches - 特征匹配模块

#### Sift.py - SIFT 特征检测
- `get_initial_matches()`: 提取初始匹配对
- 支持比例测试 (Ratio Test)
- 可视化匹配结果

#### Ransac.py - RANSAC 单应性计算
- `get_RANSAC_points()`: 计算单应性矩阵
- 内点筛选与可视化
- 几何验证

#### parallax_area.py - 视差区域点提取
- `get_true_points()`: 从外点中提取视差区域
- 基于几何一致性筛选

---

### parallax - 视差检测模块

#### SAM.py - SAM 视差分割
- `find_parallax()`: 使用 SAM 检测视差区域
- `find_parallax_batch()`: 批量处理
- 支持点提示交互

#### find_approxPolyDP.py - 视差区域处理
- `find_area()`: 查找视差区域边界
- `refine_parallax_mask()`: 优化掩码
- `get_parallax_center()`: 获取中心点

---

### stitch - 拼接模块

#### stitching_function.py - 几何变换
- `get_warp()`: 透视变换与裁剪
- `find_overlap_region()`: 重叠区域检测
- `get_canvas_size()`: 画布尺寸计算

#### energy_fuction.py - 能量函数
- `get_cost()`: 计算图割能量代价
- `get_matches_scores()`: 匹配点距离分数
- `get_point_weight()`: 高斯权重计算

#### graphcut.py - 图割与融合
- `graph_cut()`: 最大流/最小割拼接
- `gain_compensation()`: 色差校正
- `laplacian_pyramid_blend()`: 多频带融合

---

### new_idea.py - 主入口

**主要流程**：

```
1. 参数解析与初始化
   ↓
2. 图像加载与预处理 (缩放)
   ↓
3. SIFT 特征匹配
   ↓
4. 视差区域点提取 (提议方法)
   ↓
5. 透视变换与裁剪
   ↓
6. SAM 视差区域检测
   ↓
7. RANSAC 单应性计算
   ↓
8. 图像预处理 (高斯模糊)
   ↓
9. 查找重叠区域
   ↓
10. 能量函数计算
   ↓
11. 图割拼接
   ↓
12. 结果保存
```

**使用方法**：

```bash
# 基本用法
python new_idea.py --img1 img1.jpg --img2 img2.jpg --output ./output

# 完整参数
python new_idea.py \
    --img1 path/to/img1.jpg \
    --img2 path/to/img2.jpg \
    --output ./output \
    --scale 0.5 \
    --ratio-test 0.98
```
